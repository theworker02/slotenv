# slotenv

Slot digests and env fingerprints for local integrity checks.

**Site:** https://theworker02.github.io/slotenv/

## Install / run

```bash
git clone https://github.com/theworker02/slotenv.git
cd slotenv
node src/cli.js
node --test
```
